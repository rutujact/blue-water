2 Core Hydrology Execution Engine

We first transform crude precipitation series into site-specific effective inputs (\(P_{eff}\)), governed by the SCS Curve Number (\(CN\)) depending on soil type to account for surface runoff, before initializing the core water balance engine.

Code 
p.list <- list(
  precip = precip,
  et0 = et0,
  et0.timestep = et0.timestep, 
  CN = 85, 
  soil.input = "P", 
  soil.param = soil.param,
  sm.init = 0.5,
  crop.param = crop.param,
  kc_no_crop = list(summer = 0.005, kharip_rabi = 0.2)
)

# Vectorized generation of effective precipitation models across targeted soil horizons
met.forcing.ls <- lapply(as.list(soil.param$soil), function(x) {
  get_peff_et0(p = p.list, soil = x)
})
names(met.forcing.ls) <- soil.param$soil

⚡ Pro-Tip: Parallel Processing Simulating multi-decadal daily water fluxes across dozens of crop rotations is computationally expensive. The code block below detects the number of available physical cores on your machine and parallelizes the tasks, drastically reducing execution time.

Code 
# Multi-Core Setup
num_cores <- parallel::detectCores(logical = FALSE) 
cl <- makeCluster(num_cores, type = "PSOCK") 

clusterExport(cl, varlist = c("p.list", "met.forcing.ls", "get_budget", "quantile_df"), envir = environment()) 
clusterEvalQ(cl, {library(tidyverse); library(ggpubr)})

# Process budget arrays iteratively
budget <- pblapply(crop.rotation.kc.ls, get_budget, cl = cl, p = p.list, ts = met.forcing.ls)
stopCluster(cl)

names(budget) <- names(crop.rotation.kc.ls)
save(budget, file = here("output/01_processed_water_budgets.Rdata"))

# 1. Optimize Daily Processing
budget.daily.ls <- lapply(budget, function(x) {return(x$ts)})

# data.table::rbindlist is exponentially faster than dplyr::bind_rows for large lists
budget.daily <- data.table::rbindlist(budget.daily.ls, idcol = "rotation") %>%

# readr::write_csv is massively faster than base write.csv

5 Socio-Hydrological Aggregation: Production System Impact

By coupling the physical water fluxes with farm survey demographics, we aggregate individual cropping footprints into broader socio-economic archetypes. This critical step reveals how human social structures drive local water availability.

🔍 Understanding Net Consumers vs. Net Contributors

  • Irrigated Farms (\(BWP < 0\)): Commercial systems focusing on cash crops (e.g., grape vines or sweet lime) rely heavily on groundwater extraction. Because their artificial irrigation demand exceeds natural recharge over their area, they act as chronic hydrological Net Consumers.

  • Rainfed Farms & Grasslands (\(BWP > 0\)): Traditional smallholders and pastoralists operate without active groundwater pumping. A substantial fraction of seasonal monsoon precipitation infiltrates past the root zone, actively recharging the aquifer. These act as Net Contributors.

6 Macro Landscape Analysis

6.1 Historical Village Comparison

Finally, we aggregate farm-level balances to model a full archetype village. This visualization illustrates the net shift in regional water sustainability over the last several decades.

Crucially, this macro-level aggregation highlights a structural tipping point in regional water security. The baseline 1950s archetype demonstrates a robust hydrological surplus. In contrast, the 2022 configuration illustrates a system inverted by agricultural intensification. The extraction demands of intensive cropping now overwhelmingly outpace the buffering capacity of rainfed systems.

Code 
village.bwp_collapsed <- ps_bwp_volumetric %>%
  mutate(bwp_thousand_m3 = round(total_vol_m3/10000)*10) %>%
  select(time_period, production_system, bwp_thousand_m3) %>%
  mutate(production_system = case_when(
    production_system == "Landless pastoralists" ~ "Pastoralists",
    production_system == "Sheep fatteners" ~ "Pastoralists",
    production_system %in% c("Rainfed groundnut growers (with buffaloes)", "Rainfed groundnut growers (with bulls)", "Rainfed groundnut growers (with local cows)") ~ "Groundnut growers (with livestock)",
    production_system %in% c("Rainfed groundnut growers (no livestock)", "Rainfed redgram growers (no livestock)") ~ "Groundnut growers (no livestock)",
    production_system == "Rice growers" ~ "Rice growers", 
    production_system %in% c("Small-scale fruit growers (banana)", "Small-scale fruit growers (grape vines)", "Small-scale fruit growers (pomegranate)", "Small-scale fruit growers (sweet lime)") ~ "Small-scale fruit growers (+ dairy)",
    production_system %in% c("Vegetable growers (no livestock)", "Vegetable growers with dairy farming") ~ "Vegetable growers",
    TRUE ~ as.character(production_system)
  )) %>%
  group_by(time_period, production_system) %>%
  summarise(bwp_thousand_m3 = sum(bwp_thousand_m3), .groups = "drop")

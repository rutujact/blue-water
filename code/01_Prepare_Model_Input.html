Instead, use this document as a blueprint: your goal is simply to provide clean baseline data files that match the formats defined below.

0.0.1 🗂️ Workflow & Data Summary

This script processes, standardizes, and expands six distinct categories of input data required by the hydrological model:

  1. Climatic Forcings: Daily Precipitation and Reference Evapotranspiration (ET0).
  2. Soil Properties: Water Holding Capacity (WHC) and Readily Available Water (RAW).
  3. Crop Parameters: Rooting depths and irrigation constraints.
  4. Crop Coefficients (Kc): Dynamic daily vegetative growth curves.
  5. Crop Systems: Multi-season crop rotation definitions.
  6. Landscape Demographics: Cultivated area (hectares) broken down by production system and historical period.

0.0.2 📂 Directory Structure for this Script

3.2 Crop Coefficient (Kc) Expansion

We pass the baseline parameters through our biophysical expansion functions. This includes standard FAO-56 segmented curves for standard crops, derived 4th-order polynomial equations for continuous rapid growth crops like Groundnuts, and complex daily linear regrowth rates for pastures and harvested grasses.

(Note: Our functions strictly enforce a 0.01 threshold for baseline dry-season bare soil).

3.2.1 Standard FAO-56 Segmented Curves

Generates the classic 4-stage linear growth curves for standard crops.

Code 
kc.raw.long <- kc.raw %>% 
  pivot_longer(cols = -c(1, 2), names_to = "crop") %>% 
  mutate(crop = str_to_title(gsub("_|\\.", " ", crop, perl = TRUE)))

kc <- kc.raw.long %>% subset(stringr::str_detect(var, stringr::regex("kc", ignore_case = TRUE))) %>% rename(Kc = value, kc_var = var) %>%
  mutate(Kc_var = case_when(grepl("ini", kc_var, ignore.case = TRUE) ~ "Kc_ini", grepl("mid", kc_var, ignore.case = TRUE) ~ "Kc_mid", grepl("end", kc_var, ignore.case = TRUE) ~ "Kc_end", TRUE ~ kc_var))

doy <- kc.raw.long %>% subset(var %in% c("Sowing", "End of ini", "End of Dev", "End of Mid", "Harvest")) %>% rename(doy = value, doy_var = var) %>% mutate(doy = if_else(doy == 365.00, 366.00, doy))

kc.doy.key <- data.frame(doy_var = c("Sowing", "End of ini", "End of Dev", "End of Mid", "Harvest"), kc_var = c("Kc_ini", "Kc_ini", "Kc_mid", "Kc_mid", "Kc_end"))

doy <- left_join(doy, kc.doy.key, by = c("doy_var"))
kc.doy <- left_join(doy, kc, by = c("kc_var", "crop")) %>% arrange(crop, doy, Kc) %>% mutate(doy = as.numeric(doy), Kc = as.numeric(Kc))

kc.doy.crops <- kc.doy %>% select(crop, doy_var, doy, Kc) %>%
  mutate(doy_var = factor(doy_var, levels = c("Sowing", "End of ini", "End of Dev", "End of Mid", "Harvest"))) %>%
  arrange(crop, doy, doy_var)

kc_wide_build <- kc.doy.crops %>%
  pivot_wider(names_from = doy_var, values_from = c(doy, Kc)) %>%
  rename(
    Sow = doy_Sowing, E_ini = `doy_End of ini`, E_dev = `doy_End of Dev`,
    E_mid = `doy_End of Mid`, Harv = doy_Harvest,

  mutate(crop = str_to_title(gsub("_", " ", crop, perl = TRUE)))

  geom_line(linewidth = 1) + facet_wrap(~ crop) + theme_baseR +

4.0.1 Classify Production Systems by Hydrological Typology

Farm production systems are highly heterogeneous. Because irrigation drives a disproportionately high water deficit, classifying farms strictly by majority land area underestimates their hydrological impact. Instead, we use a hierarchical threshold to define the System Typology. If a production system dedicates a significant threshold of its land (\(\geq 35\%\)) to irrigation, it is classified as “Irrigation-Driven,” regardless of its remaining acreage.

Code 
# 1. Map Crop Systems to Core Surface Types
cs_surface <- crop.systems %>%
  select(crop.system, Irrigation) %>%
  distinct() %>%
  mutate(
    land_use = case_when(
      Irrigation == "Irrigated" ~ "Irrigated",
      str_detect(crop.system, "(?i)grassland|grazed|pasture") ~ "Pastoral",
      TRUE ~ "Rainfed"
    )
  )

# 2. Calculate area percentages and pivot to wide format
ps_typology <- ps_by_cs_area %>%
  left_join(cs_surface, by = "crop.system") %>%
  group_by(time_period, production_system, land_use) %>%
  summarise(land_use_area = sum(area_ha, na.rm = TRUE), .groups = "drop_last") %>%
  mutate(
    total_area_ha = sum(land_use_area, na.rm = TRUE),
    land_use_pc   = round((land_use_area / total_area_ha) * 100, 2)
  ) %>%
  ungroup() %>%
  select(-land_use_area) %>%
  pivot_wider(names_from = land_use, values_from = land_use_pc, values_fill = 0) %>%
  mutate(
    system_typology = case_when(
      Irrigated >= 35 ~ "Irrigated",
      Pastoral > Rainfed ~ "Pastoral",
      TRUE ~ "Rainfed"
    )
  ) %>%
  select(time_period, production_system, total_area_ha, Irrigated, Pastoral, Rainfed, system_typology)

# Save the structured classification for downstream plotting
write.csv(ps_typology, file = here("data/processed/supplementary/05_production_system_typology.csv"), row.names = FALSE)
